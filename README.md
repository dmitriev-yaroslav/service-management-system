# Service Management System

Информационная система для автоматизации бизнес-процессов сервисного обслуживания, разработанная на базе Odoo 17 и Drupal 11.

## О проекте

Проект выполнен в рамках выпускной квалификационной работы по направлению «Прикладная информатика».

Цель проекта - автоматизация процессов сервисного обслуживания компании на примере ООО «Профгарантстрой». Система объединяет обработку заявок, планирование выездов специалистов, учет материалов, формирование документов и взаимодействие между внутренними сервисами.

В качестве платформ использованы Odoo 17 и Drupal 11, обмен данными между которыми реализован через REST API.

## Используемые технологии

- Odoo 17
- Drupal 11
- Python
- PHP
- PostgreSQL
- REST API

## Структура репозитория

Работа над оформлением репозитория продолжается. Постепенно будут добавлены исходный код разработанных модулей, диаграммы, документация и материалы проекта.
